# Simple LLM Chatbot

## 1. Project Overview

This project demonstrates a simple Large Language Model
application using Python and HuggingFace Transformers.

The application loads a pretrained language model and provides
a simple text generation chatbot interface.

## 2. Objectives

The objectives of this project are:

- Load a pretrained language model.
- Integrate the model using HuggingFace Transformers.
- Build a simple chatbot.
- Test model functionality and output.
- Measure latency and resource usage.

## 3. Technologies

- Python
- PyTorch
- HuggingFace Transformers
- pytest
- psutil
- GitHub
